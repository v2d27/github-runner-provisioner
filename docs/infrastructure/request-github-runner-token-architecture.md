# request-github-runner-token-architecture

- **Never to GitHub user PAT at all**.
- **Try to use 1 time GitHub Apps setup**

For your architecture, use a **GitHub App**, not a Personal Access Token.

```text
                    GitHub
                       ▲
                       │
              GitHub App API
                       │
                ┌──────┴──────┐
                │    Lambda   │
                │             │
                │ App ID      │
                │ Private Key │
                └──────┬──────┘
                       │
                       │ Installation Access Token
                       ▼
              GitHub REST API
                       │
                       │ registration token
                       ▼
                  EC2 Runner
```

### Authentication flow

Lambda does:

```text
1. GitHub App Private Key
        ↓
2. Generate App JWT
        ↓
3. JWT → Installation Access Token
        ↓
4. Installation Token → runner registration token
        ↓
5. Give registration token to EC2 bootstrap
```

There is **no PAT anywhere**.

For example, the API call Lambda makes is conceptually:

```http
POST /orgs/{org}/actions/runners/registration-token
Authorization: Bearer <installation_access_token>
```

or, for a repository:

```http
POST /repos/{owner}/{repo}/actions/runners/registration-token
Authorization: Bearer <installation_access_token>
```

The important part is that:

```text
PAT                         ❌
GitHub App Private Key      ✅ Lambda only
Installation Access Token   ✅ generated by Lambda
Runner Registration Token   ✅ short-lived
```

### For your dynamic runner system

I would specifically structure it as:

```text
GitHub
  │
  │ webhook
  ▼
Lambda
  │
  ├── Validate webhook
  │
  ├── Determine:
  │     ├── runner prefix
  │     ├── runner group
  │     └── repository
  │
  ├── GitHub App authentication
  │
  ├── Get installation token
  │
  ├── Get runner registration token
  │
  └── Provision EC2
           │
           └── registration token
                    ▼
               GitHub Runner
```

And your EC2 instance **never receives**:

```text
GitHub App private key ❌
GitHub App JWT            ❌
Installation token        ❌
PAT                       ❌
```

It only receives the **temporary runner registration token** needed to register itself.

So yes: **GitHub App + Lambda is fully sufficient; PAT is unnecessary.**
